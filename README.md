# Lean Production Playbook

[中文](#中文说明) · [English](#english)

## English

`changing-the-world-machine` is a private agent skill for applying lean-production thinking to end-to-end value creation. It helps an agent analyze operations, product development, supply-chain collaboration, customer relationships, and organizational transformation through practical decision rules rather than isolated tools.

### What’s included

- Core lean-production frameworks and mental models
- Ten on-demand chapter guides
- A glossary, implementation patterns, and a decision cheatsheet
- Guidance for value-stream diagnosis, root-cause resolution, pull systems, cross-functional development, and supplier collaboration

### Install

```bash
npx skills add https://github.com/bolin0759/lean-production-playbook --skill changing-the-world-machine
```

### Use

Ask your agent to use `changing-the-world-machine`, then provide a topic or chapter, for example:

```text
Use changing-the-world-machine to diagnose why our delivery lead time is long.
Use changing-the-world-machine to design a supplier-improvement workshop.
Explain ch04 of changing-the-world-machine.
```

### Contents

```text
SKILL.md                 Core frameworks and topic index
chapters/                Ten focused chapter guides
glossary.md              Key terms and definitions
patterns.md              Repeatable implementation patterns
cheatsheet.md            Decision rules and diagnostic prompts
```
